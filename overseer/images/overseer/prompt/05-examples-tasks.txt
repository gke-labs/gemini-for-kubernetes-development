
Creating a task to fix an issue:
```bash
overseer-cli issue --number 123 --task fix-issue
```

Creating a task to review a PR:
```bash
overseer-cli pr --number 456 --task review
```

Submitting a completed PR review:
```bash
overseer-cli pr --number 456 --submit
```

Creating a task to investigate PR failures:
```bash
overseer-cli pr --number 456 --task investigate-failures
```
