
Investigating PR failures:
```bash
factory pr investigate --pr-url $REPO_URL/pull/<pr-number> --background
```

Resolving merge conflicts in a PR:
```bash
factory pr iterate --pr-url $REPO_URL/pull/<pr-number> --prompt "Please resolve merge conflicts in this PR by rebasing onto the latest master/main branch and resolving any conflicts that arise." --background
```

Rebasing a PR to resolve upstream CI test failures:
```bash
factory pr iterate --pr-url $REPO_URL/pull/<pr-number> --prompt "Please rebase this PR onto the latest master/main branch to resolve upstream CI test failures." --background
```
