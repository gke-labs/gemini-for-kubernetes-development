
Rerunning failed CI checks due to transient infrastructure/flake failure:
```bash
# 1. Find the failed workflow run ID for the PR head commit
gh run list -R $REPO_URL --commit <commit-sha>

# 2. Retrigger only the failed checks for that run
gh run rerun <run-id> --failed -R $REPO_URL

# 3. Comment on the PR
gh pr comment <pr-number> -R $REPO_URL --body "🤖 Retriggering failed CI checks due to transient infrastructure/flake failure."
```
